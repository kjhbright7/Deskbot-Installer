ESP32-C3 미연결

USB 케이블 연결 후 1단계 버튼을 눌러주세요

연결 끊김

엔진 펌웨어 및 기기 연동

USB 케이블로 PC와 ESP32-C3 보드를 연결한 뒤 아래 순서대로 진행하세요.

1단계: 기기 통신 연결

보드와 브라우저 간의 시리얼 데이터 통신을 연결합니다.

2단계: 펌웨어 다운로드

ESP Web Tools를 통해 보드에 최신 코드를 직접 굽습니다.

기기 네트워크 & 커플 연동 초기 설정

스마트폰 AP 연결 없이, PC에서 Wi-Fi 정보와 커플 코드를 보드의 플래시 메모리에 즉시 저장합니다.

ℹ️ 기기 상단 상태 표시줄에는 영문 폰트만 지원되므로 영문 대문자만 입력 가능합니다.

하드웨어 배선 안내

부품부품 핀ESP32-C3 핀
0.96인치 OLEDSDA / SCLGPIO 8 / GPIO 9
0.96인치 OLEDVCC / GND3.3V / GND
리미트 스위치NO / COMGPIO 7 / GND

3.2초마다 눈을 깜빡이는 생동감 있는 표정들입니다. 원하는 표정을 클릭해 보세요.
